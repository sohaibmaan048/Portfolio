# My First Week Learning Python: The Beginning of My Programming Journey



When I started my Computer Engineering degree, I knew that programming would become an important part of my academic journey. However, knowing that programming is important and actually writing code are two completely different things. My first week of learning Python in the Programming Fundamentals course was exciting, confusing, and challenging at the same time. Looking back now, I can confidently say that those early struggles became the foundation of everything I learned later in software development, databases, and machine learning.



Before entering university, I had heard about programming languages and software development, but I had never worked seriously on programming projects. Like many first-year students, I assumed programming was mainly about memorizing commands and learning syntax. During the first few classes, I quickly discovered that programming is actually about solving problems and developing logical thinking skills.



---



> **"Programming is not about memorizing commands. It is about learning a new way to think."**



---



## The First Challenge: Understanding Structure



The first challenge I faced was understanding the structure of Python programs. Even writing a simple program that displayed text on the screen felt unfamiliar. Terms such as variables, data types, input statements, and output functions seemed completely new. Every line of code looked complicated, and I often wondered how experienced programmers could write large programs without getting confused.



One aspect of Python that surprised me was the importance of indentation. A small spacing mistake could cause an error, and it was frustrating to see a program fail because of something that looked insignificant. During the first few lab sessions, I spent a lot of time trying to understand why my code was not working correctly. Sometimes the issue was a missing bracket. Other times it was a spelling mistake in a variable name. Although these mistakes were small, they taught me an important lesson about attention to detail.



```python
# My very first Python program
print("Hello, World!")

# A simple variable example
name = "Sohaib"
print("My name is", name)
```



## Learning by Doing



As the weeks progressed, I realized that programming could not be learned through theory alone. Reading notes helped me understand concepts, but actual learning happened when I wrote code myself. I started spending extra time practicing simple programs outside the classroom. I experimented with different inputs, modified examples from lectures, and observed how the output changed.



At first, progress felt slow. There were moments when even a basic program seemed difficult to complete. However, every successful execution of a program gave me a sense of achievement. Seeing my code run correctly after multiple failed attempts was surprisingly motivating. Those small victories helped me stay committed to learning.



One thing that stood out during the course was the emphasis on practical learning. Instead of focusing entirely on theoretical concepts, we were encouraged to apply ideas through coding exercises and lab activities. This approach helped me understand that programming is a skill that develops through practice rather than memorization.



Another important lesson I learned was patience. Programming has a way of exposing mistakes that are often hidden in plain sight. There were times when I spent thirty minutes searching for an error that was caused by a single missing character. Initially, this process felt frustrating. Over time, I realized that debugging is a normal part of programming and an essential skill for every developer.



---



## Key Lessons from My First Week



| Lesson | What It Taught Me |
|---|---|
| Attention to detail | One missing character can break an entire program |
| Patience | Debugging is not a failure — it is part of the process |
| Breaking problems down | Solve small steps first, then scale up |
| Consistency | Progress lives in daily practice, not occasional effort |



---



## Lessons That Went Beyond the Code



Perhaps the most valuable change during this period was the way programming influenced my thinking. Before learning Python, I often looked at problems as complete tasks. Programming taught me to break large problems into smaller manageable parts. Instead of trying to solve everything at once, I learned to analyze problems step by step. This mindset proved useful not only in programming but also in other academic subjects.



As my confidence grew, I became curious about the broader world of computing. Learning Python introduced me to areas such as software development, automation, data analysis, artificial intelligence, and machine learning. Although I was still a beginner, I could already see how programming serves as the foundation for many modern technologies.



During discussions throughout the semester, there was frequent emphasis on solving real-world problems through technology. This idea stayed with me because it connected classroom learning with practical applications. Understanding that programming skills can be used to build useful solutions made the learning process more meaningful.



## Why I Document This on GitHub



Looking back today, my first week of learning Python was not about mastering a programming language. It was about building the foundation of a new way of thinking. The confusion, mistakes, and challenges were all part of the learning process. Every error message, every failed program, and every debugging session contributed to my growth as a student.



This experience also reminds me why I created this GitHub portfolio. The goal is not simply to showcase projects but to document my learning journey as a Computer Engineering student. Recording these experiences creates a digital footprint that reflects both my technical development and personal growth over time.



For students who are beginning their own programming journey, my advice is simple. Do not become discouraged by early difficulties. Every programmer starts as a beginner. The key is consistency. Practice regularly, learn from mistakes, and focus on understanding concepts rather than memorizing code. Progress may seem slow at first, but every small improvement contributes to long-term growth.



My first week with Python marked the beginning of a journey that continues today. While I still have much to learn, I am grateful for those early experiences because they taught me resilience, patience, and problem solving. These lessons continue to influence how I approach technical challenges and new opportunities.



Learning basic Python syntax was only the beginning. The next challenge was understanding how variables, conditions, and loops work together to solve real problems. That experience became the next important step in my Programming Fundamentals journey.
